# 拾光集（ShiGuangJi）· 校园二手交易平台

> 拾取好物，重拾时光 —— 仅限本校在校学生使用的二手交易平台 · 强认证 · 仅撮合线下当面交易

**「拾」**取二手好物，让旧物重获新生；**「拾光」**谐音“时光”，每一件二手物件都承载着一段校园记忆。

面向校园场景的二手交易产品，目标是承接「校园集市 / 跳蚤市场」的线下交易需求并线上化。核心差异点为 **严格的学生身份认证** 与 **校园（楼栋 / 寝室级）导航路书**。

---

## 产品定位

- **用户范围**：仅本校在校学生（强认证，杜绝校外人员）。
- **交易模式**：平台只做信息撮合，买卖双方 **校内当面交易**（一手交钱一手交货），平台不经手货款、不做资金担保。
- **平台节奏**：第一版做 **微信小程序**（扫码即用、便于校园裂变传播）；功能完整后再开发 **安卓 App**（复用同一套后端）。

## 交付物一览

1. **需求验证问卷**（`docs/需求验证问卷.docx`）——5 大部分 22 题，覆盖用户背景、二手交易习惯与痛点、强认证接受度、导航路书需求、使用与付费意愿。用于阶段 0 需求验证（问卷 + 地推 + 访谈）。
2. **MVP PRD**（`docs/MVP产品需求文档PRD.docx`）——含产品定位与边界、用户角色权限、**功能清单（26 项，标注 P0/P1/P2 优先级）**、核心业务流程、页面结构与信息架构、数据模型、非功能需求、技术选型、里程碑排期、风险对策。
3. **页面原型**（`prototypes/prototype.html`）——首页 / 商品详情 / 发布 / 学生认证 / 聊天 / 个人中心 6 个页面，手机尺寸，浏览器直接查看。
4. **流程图**（`prototypes/flowchart.html`）——学生认证、发布商品、撮合交易、全局页面跳转 4 张 SVG 流程图。
5. **微信小程序 MVP**（`miniprogram/`）——微信原生 + 云开发，8 个页面跑通 P0 全流程（认证拦截、多图上传、撮合交易闭环）。v0.3.0 起核心链路为**云端真实逻辑**：消息 `.watch()` 实时同步、邮箱验证码服务端生成/校验（可配 SMTP 真实发信）、交易双向确认服务端闭环并自动标记已售。**零配置仍可用 mock 数据预览**。详见 `miniprogram/README.md`。

## 如何查看

- **文档**：用 Word / WPS 打开 `docs/` 下的 `.docx`。
- **原型与流程图**：用浏览器（Chrome / Edge）直接打开 `prototypes/` 下的 `.html`。
- **重新生成文档**：需要 Python 3 + `python-docx`。
  ```bash
  python scripts/gen_questionnaire.py
  python scripts/gen_prd.py
  ```

## 技术选型（建议）

- 小程序端：微信原生 / uni-app（便于二期复用到 App）
- 后端：Spring Boot / NestJS + PostgreSQL + Redis
- IM：第三方（融云 / 环信）或自建 WebSocket
- 存储：阿里云 OSS / 腾讯云 COS　｜　地图：高德地图 SDK
- OCR / 学籍核验：腾讯云 / 阿里云（需企业资质）
- 后台：Vue / React + Ant Design

## 合规提示

学生姓名、学校、学号、证件照等属《个人信息保护法》下的敏感个人信息，须做到：明确隐私政策与用户协议、最小化收集、加密存储、审核后脱敏 / 限期删除。违禁品（管制刀具、药品等）禁止交易。
