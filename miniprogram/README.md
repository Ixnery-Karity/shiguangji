# 拾光集 · 微信小程序（MVP）

仅限本校认证学生的二手交易小程序，**微信原生 + 微信云开发**，仅撮合、线下当面交易。

## 目录结构

```
miniprogram/                    # 项目根（用微信开发者工具导入这一层）
├── project.config.json         # 工程配置（云开发模式）
├── miniprogram/                # 小程序前端代码
│   ├── app.js / app.json / app.wxss
│   ├── components/item-card/   # 商品卡片组件
│   ├── pages/
│   │   ├── home/               # 首页（瀑布流+搜索历史/热词+排序/成色筛选）
│   │   ├── detail/             # 商品详情
│   │   ├── publish/            # 发布（认证拦截+上传图+违禁词）
│   │   ├── auth/               # 学生认证（邮箱+学生证两级）
│   │   ├── chatList/           # 消息列表
│   │   ├── chatRoom/           # 聊天会话 + 发起交易/双向确认
│   │   ├── trade/              # 我的交易 / 我发布的 / 我的收藏
│   │   └── mine/               # 个人中心
│   └── utils/                  # util / db（数据访问层）/ mock（演示数据）
└── cloudfunctions/             # 云函数
    ├── login/                  # 获取 openid
    ├── seed/                   # 初始化集合 + 写入演示商品
    ├── authEmail/              # 【v0.3.0】邮箱验证码：服务端生成/校验，可配 SMTP 真实发信
    ├── tradeConfirm/           # 【v0.3.0】交易双向确认：双方完成后自动标记商品已售
    └── itemView/               # 【v0.4.0】商品浏览量服务端自增
```

## 快速开始

### 方式 A：仅看界面和流程（零配置）

1. 打开**微信开发者工具**，导入本目录（选到含 `project.config.json` 的 `miniprogram/` 目录）。
2. AppID 选择「测试号」。
3. 直接编译预览。此时 `utils/db.js` 会**自动回退到 mock 演示数据**，首页、详情、发布、认证、聊天、交易全流程可点通（首页顶部有「演示数据」提示条）。

### 方式 B：接入真实云开发（可发布/存储真实数据）

1. 在开发者工具**开通云开发**（顶部「云开发」按钮，按引导创建环境，记下**环境 ID**）。
2. 打开 `miniprogram/app.js`，把 `env: wx.cloud.DYNAMIC_CURRENT_ENV` 换成你的环境 ID：
   ```js
   wx.cloud.init({ env: '你的环境ID', traceUser: true });
   ```
3. **部署云函数**：对 `cloudfunctions/` 下的 `login`、`seed`、`authEmail`、`tradeConfirm`、`itemView` 逐个右键 →「创建并部署：云端安装依赖」。
4. **初始化数据**：在开发者工具「云开发控制台 → 云函数 → seed」点击「云端测试」运行一次；或临时在页面调用 `wx.cloud.callFunction({name:'seed'})`。会自动创建 `users/items/chats/messages/trades/authRecords/authCodes/reports/favorites` 集合并写入演示商品。
5. 云数据库集合权限建议：`items` 设为「所有用户可读，仅创建者可写」；`chats/messages` 设为「所有用户可读，仅创建者可写」（双方需互读）；`users/trades/authCodes/favorites` 设为「仅创建者可读写」（trades 状态由 `tradeConfirm` 云函数以管理员权限更新；items 浏览量由 `itemView` 云函数更新）。
6. **（可选）真实发送验证码邮件**：在云开发控制台给 `authEmail` 云函数配置环境变量 `SMTP_HOST / SMTP_PORT / SMTP_USER / SMTP_PASS`（如学校企业邮箱或 QQ 邮箱 SMTP）。未配置时验证码以演示方式返回前端。
7. 重新编译，首页即显示云端真实商品。

## 说明与边界（演示 vs 生产）

| 能力 | 当前实现（v0.4.0） | 生产建议 |
| --- | --- | --- |
| 邮箱验证码 | ✅ `authEmail` 云函数服务端生成/存储/校验（60s 限频、5min 过期、一次性使用）；配置 SMTP 后真实发信，未配置返回演示码；无云环境回退本地演示码 | 配置 SMTP 环境变量即为生产逻辑；生产务必配置，勿向前端返回验证码 |
| 学生证审核 | 提交后模拟通过 | 上传 `authRecords` 待审，后台人工复核后升级 |
| 聊天 | ✅ 云端 `chats/messages` 集合真实读写 + `.watch()` 实时监听，双端消息实时同步；无云环境回退单页演示对话 | 大规模场景可换第三方 IM（融云/环信）；当前实现已可支撑校内量级 |
| 交易双向确认 | ✅ `tradeConfirm` 云函数服务端判定角色、双方各自确认，两端都 done 才闭环并**自动标记商品已售**；交易状态 `.watch()` 实时同步；无云环境回退演示 | 已为生产逻辑；可补充超时自动关闭、评价互评 |
| 违禁词 | 前端常量清单 | 云端配置 + 图片鉴黄 |
| 收藏 | ✅ 云端 `favorites` 集合持久化；无云/未登录回退本地缓存 | 已为生产逻辑；可补收藏数聚合展示 |
| 未读消息 | ✅ 会话文档 `buyerUnread/sellerUnread` 计数，发消息服务端 inc、进会话清零，消息 tab 徽标 | 已为生产逻辑；大量会话时可改聚合查询 |
| 浏览量 | ✅ `itemView` 云函数 inc，客户端异步触发 | 可加去重（同人同日一次） |
| 热门搜索词 | 前端常量清单 | 云端搜索日志聚合 |
