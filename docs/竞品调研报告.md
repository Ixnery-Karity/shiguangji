## 二、核心竞品拆解

### 1. 闲鱼 —— 功能标杆
- **信任体系**：芝麻信用分展示、实人认证标识、卖家历史成交与好评率。
- **商品体验**：瀑布流 + 搜索历史/热门词、成色标签（全新/几成新）、浏览量与「想要」数、卖家其他在售、同类推荐。
- **激活机制**：「擦亮」让商品重回列表顶部；降价提醒触达收藏者。
- **社区**：曾经的「鱼塘」演化为兴趣/学校圈层，校园频道靠学生认证聚合同校供需。
- **交易**：支付宝担保 + 快递为主，当面交易为辅。
- **对本项目的启示**：搜索历史、成色筛选、收藏持久化、浏览量、卖家主页/在售列表是二手平台的「及格线」功能；信用展示（成交笔数+好评率）是促成交的关键信息。

### 2. 转转 —— 质检信任
- 官方验机报告、履约保障、平台中介担保。
- **启示**：中心化质检成本高，不适合校园撮合模式；但「当面验货话术提示」「交易留痕」可低成本借鉴（本项目已有雏形）。

### 3. 多抓鱼 —— 品类循环
- 扫码即卖、官方定价回收、翻新再售，书籍品类体验极佳。
- **启示**：教材是校园二手最高频品类，可做「教材专区」+ ISBN 扫码带出书目信息（二期）。

### 4. 校园跳蚤群 / 表白墙 —— 现状替代品（真正要打败的对象）
**痛点**（本项目的机会点）：
1. 信息流噪音大，无结构化（找一本教材要翻几百条群消息）；
2. 无身份保障，校外二道贩子混入，诈骗时有发生；
3. 无沉淀：成交不留痕、无信用积累、无法搜索历史商品；
4. 无状态管理：卖掉的东西还在被询问。

**本项目对位打法**：强认证（杜绝校外人员）→ 结构化商品流（分类/搜索/筛选）→ 交易留痕与双向确认 → 信用积累。

## 四、结论：v0.4.0 更新范围（已确认）

1. **收藏真实化**：云端 `favorites` 集合持久化（无云环境回退本地缓存），详情页收藏状态恢复，「我的收藏」列表，个人中心统计联动。
2. **搜索与筛选升级**：搜索历史（本地缓存、可清空）+ 热门搜索词 + 排序（最新/价格升/价格降）+ 成色筛选。
3. **未读消息红点**：会话级未读计数（服务端字段）+ 消息 tab 徽标 + 进入会话清零。
4. **详情页增强**：浏览量统计与展示、卖家其他在售、同分类相关推荐。

### 后续版本建议（按 ROI 排序）
- v0.5.0：擦亮/重新上架、降价通知收藏者、求购区、卖家主页（信用聚合真实化）。
- v1.x：教材 ISBN 扫码建档（差异化+高频）、导航路书（核心差异化）。

## 五、风险提示

- 闲鱼校园频道若在目标校重点运营，将挤压生存空间 → 打法：更强的同校信任（认证）+ 线下当面零风险 + 楼栋导航的「最后一百米」体验。
- 校园群迁移成本：冷启动需地推与种子卖家（毕业季集中供给是最佳切入时点）。
